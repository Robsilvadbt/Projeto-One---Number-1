# Amigo Secreto

Um jogo simples para sortear amigos secretos!

## Descrição

Este projeto é um jogo "Amigo Secreto" desenvolvido em JavaScript, HTML e CSS. Ele permite que você adicione nomes de amigos a uma lista e, em seguida, sorteie um amigo aleatoriamente para cada participante.

## Funcionalidades

*   **Adicionar nomes:** Adicione o nome de um amigo à lista através de um campo de texto.
*   **Validação de entrada:** O programa verifica se o campo de texto está vazio e exibe um alerta caso esteja.
*   **Visualizar lista:** Os nomes adicionados são exibidos em uma lista na página.
*   **Sorteio aleatório:** Ao clicar no botão "Sortear Amigo", um nome aleatório da lista é selecionado e exibido como o amigo secreto sorteado.

## Como usar

1.  Clone este repositório para o seu computador.
2.  Abra o arquivo `index.html` em seu navegador.
3.  Insira os nomes dos seus amigos no campo de texto e clique em "Adicionar".
4.  Repita o processo para adicionar todos os participantes.
5.  Clique no botão "Sortear Amigo" para revelar o amigo secreto sorteado.
